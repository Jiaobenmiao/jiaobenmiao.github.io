04常见问题

关于脚本喵, 你可能想知道的。

脚本喵需要安装 Python 或任何运行环境吗?
不需要。脚本喵是打包好的单文件 EXE, 内置全部运行环境, 双击即用, 首次启动约 8 秒完成解压。
免费版和完整版有什么区别?
免费版可使用 6 个核心动作(点击 / 移动鼠标 / 循环 / 跳出循环 / 点击图片 / 输入文字), 体验完整工作流; 完整版一次性买断, 解锁全部 26 种动作、定时启动与准星选窗, 一台设备永久使用。
运行脚本时, 鼠标还能做别的事吗?
可以。脚本喵支持后台运行模式, 锁定目标窗口后脚本在窗口内运行, 不占用你的真实鼠标, 可以同时处理其他工作。
脚本运行出错了怎么办?
按 F8 可随时紧急停止, 鼠标甩到屏幕左上角也能急停。日志区会实时显示每个步骤的执行进度, 方便定位问题。
激活码可以换电脑用吗?
激活码绑定本机机器码(CPU + 网卡 + 主机名生成)。换电脑需重新生成激活码, 请联系作者获取。
有使用教程吗?
有。内置文档位于 设置 → 关于 / 快捷键 / 行为偏好; 也可以在官网查看详细图文教程。
