杀毒误报 / 安装后打不开，怎么办

脚本喵是 Windows 自动化工具（模拟鼠标键盘、识别屏幕内容），这类行为与部分木马特征重合，加上软件尚未购买代码签名证书，被杀毒软件误报、被 SmartScreen 拦截是常见现象。按本页步骤操作即可正常使用，你的系统没有任何问题。

📌 先说结论：① 下载后首次运行弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」；② 安装后双击没反应 → 十有八九是杀毒把程序文件拦了，把安装目录加进白名单再启动；③ 还不行 → 把 %TEMP%\jiaobenmiao_boot.log 发给作者，一看便知。

一、按症状对号入座

🚫 下载时就被拦 / 安装包被删

  • 浏览器下载完成即提示「有病毒」或文件消失
  • 先在杀毒软件里恢复该文件，再把安装包加入白名单/信任区，重新安装
  • 务必从官网 jiaobenmao.com 下载，别用第三方转发版

🖱 双击图标完全没反应

  • 最常见：杀毒在安装解压时悄悄吞掉了程序文件
  • 安装完成页若提示「关键文件缺失」，就是它 —— 加白名单后重装
  • 打开任务管理器看有无 脚本喵.exe 进程：闪一下就没了 = 被当场拦截

⚠️ 首次运行弹「Windows 已保护你的电脑」

  • 这是 Windows SmartScreen，不是病毒
  • 点弹窗上的「更多信息」→「仍要运行」即可，只需一次
  • 详见下载页图示

二、把脚本喵加入白名单（按你的杀毒软件选）

🛡 Windows Defender（Win10/11 自带）

1
打开设置

Windows 安全中心 →「病毒和威胁防护」→「管理设置」

2
添加排除项

「添加或删除排除项」→「添加文件夹」→ 选择安装目录（默认 C://Program Files\脚本喵）

3
恢复被拦文件

「保护历史记录」里若有脚本喵相关记录，选「允许」；然后重新安装一次

🔵 360 安全卫士

1
木马查杀 → 恢复区/信任区

若脚本喵被隔离，选「恢复」并「加入信任」

2
手动加信任

「木马查杀」→「信任区」→「添加目录」→ 选择 C://Program Files\脚本喵

3
重装

加完白名单再运行安装器，避免再次被吞文件

🟢 腾讯电脑管家

1
病毒查杀 → 隔离区

找到脚本喵相关文件，选「恢复」

2
添加信任

「设置中心 → 信任区」→ 添加安装目录；或「实时防护」里允许脚本喵

🟠 火绒安全

1
病毒查杀 → 隔离区

恢复被拦文件

2
信任区

「安全工具 → 信任区」→ 添加 C://Program Files\脚本喵 整个目录

三、还是打不开？把日志发给作者（10 秒定位）

📋 启动日志在哪

脚本喵每次启动都会写一份「启动日志」，死在哪一步里面写得清清楚楚：

1
按 Win+R

输入 %TEMP% 回车，打开临时文件夹

2
找文件

把 jiaobenmiao_boot.log（若还有 jiaobenmiao_boot.crash.log 一并）发给作者

3
顺手确认

安装目录里 _internal 文件夹是否在、是否有一万多个文件（缺文件就是被杀毒吞了）
